# Featured thumbnails

Drop vertical screenshots of your TikToks/videos here, then register them
in `src/config/featured.ts` (the guide at the top of that file walks
through it).

Image tips:

- Vertical crops work best — the cards display at a 4:5 ratio and
  auto-crop anything taller (like a 9:16 TikTok frame) from the center.
- A width of ~600–800px is plenty; bigger files just slow the page down.
- `.jpg`, `.png`, and `.webp` all work.
